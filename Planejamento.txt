## 🎯 OBJETIVO FINAL:
Criar um sistema completo, automatizado e profissional de operações na Deriv, com painel web, estratégias inteligentes, login integrado e potencial de venda como SaaS (serviço) para clientes iniciantes e intermediários no mercado.

---

## 🧱 ESTRUTURA DO PROJETO:

**1. Backend (Python + Flask)**
- `app.py`: Servidor principal, rotas, login, integração com painel
- `bot_deriv.py`: Robô de operações com estratégias e WebSocket
- `catalogador.py`: (futuro) Estratégias de análise para tomada de decisão
- `config.txt`: Arquivo de configurações para token, valores, modo etc.

**2. Frontend (HTML + JS + CSS)**
- `index.html`: Painel principal com login, seleção de modo, logs e resultados
- `static/`: Estilos e scripts JS
- Login com Google (futuro)

**3. Utilidades**
- `iniciar_servidor.bat`: Arquivo para abrir o sistema com 2 cliques
- `versao_mobile.html`: Otimização para celular

---

## 🔁 FUNCIONAMENTO COMPLETO:

1. Usuário acessa `index.html` e faz login (senha ou Google)
2. Escolhe modo de operação: Iniciante / Conservador / Agressivo
3. Clica em “Iniciar Robô”
4. Backend ativa `bot_deriv.py`, que:
   - Conecta via WebSocket na Deriv
   - Consulta saldo
   - Escolhe direção com base em estratégias (confirmação múltipla)
   - Entra nas operações automáticas
   - Mostra logs no painel e retorno de resultados
